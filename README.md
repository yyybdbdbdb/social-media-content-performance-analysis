
# Social Media Content Performance Analysis

## Project Overview
This project analyzes social media content performance to identify patterns in views, engagement, content formats, platforms, regions, and publishing times.

The dataset contains approximately 5,600 posts published between January 2024 and May 2025 across six social media platforms and eight regions.

## Business Objective
To identify which platforms, content categories, post formats, regions, and publishing times are associated with stronger reach and engagement, and to recommend data-driven strategies for the next quarter.

## Tools & Technologies
- **Python:** Data cleaning, validation, and exploratory data analysis
- **SQL:** Data analysis and business queries
- **Power BI:** Interactive dashboards and visual reporting
- **Excel:** Initial data inspection and data quality assessment
- **GitHub:** Project documentation and version control

## Key Business Insights
1. **Platform performance:** Instagram achieved the highest average recalculated engagement rate at approximately 15.85%.
2. **Content format:** Video posts averaged approximately 1.235 million views and 160,000 engagements.
3. **Sponsored content:** Sponsored posts averaged approximately 974K views compared with 835K for organic posts.
4. **Regional differences:** Leading platforms varied by region, supporting localized content strategies.
5. **Publishing time:** Saturday recorded the highest average engagement among the days analyzed.

## Data Quality & Limitations
- Clicks and click-through rate (CTR) were missing for 3,740 posts, approximately 66.8% of the dataset.
- Missing values were not automatically treated as zero.
- Observed patterns indicate associations and do not prove causation.
- May 2025 contained only 10 posts, so its results may not be representative.

## Recommendations
- Test video formats and platform-specific content strategies.
- Evaluate sponsored campaigns using spending and conversion data before drawing ROI conclusions.
- Improve click and CTR tracking consistency.
- Review performance by platform, region, content category, and publishing time.

## Project Deliverables
- Python exploratory analysis notebook
- SQL analysis queries
- Power BI interactive dashboard
- Business insights and recommendations report

## Conclusion
This project demonstrates how data analysis can transform social media metrics into actionable insights to support content planning and performance monitoring.
